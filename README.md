# Gerador de Citações

Este projeto é uma aplicação desenvolvida em **React JS** com o objetivo de gerar e exibir citações de forma simples e dinâmica.

## Funcionalidades

- Exibe uma citação e o nome do autor.
- Possui um botão para gerar uma nova citação.
- Interface estilizada com **Tailwind CSS**.
- Estrutura baseada em componentes React.

## Tecnologias utilizadas

- React JS
- JavaScript
- Tailwind CSS

## Objetivo

O projeto foi criado como exercício prático para trabalhar conceitos de React, como:

- Componentes
- Props
- `useState`
- Eventos com `onClick`
- Estilização com Tailwind CSS

## Exemplo de uso

Ao abrir a aplicação, o usuário visualiza uma citação na tela. Ao clicar no botão **"Nova Frase"**, uma nova citação pode ser exibida.

## Execução do projeto

Instale as dependências:

```bash
npm install
```

Depois, execute:

```bash
npm start
```

A aplicação será aberta no navegador, normalmente em:

```text
http://localhost:3000
```
